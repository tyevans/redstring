## Which Tutorial Should I Start With?

- **If you want to use redstring in your project**, start with [Your First Graph](../getting-started.md) and the [Installation](../installation.md) guide.
- **If you want to contribute to redstring or run autonomous agent workflows**, start with [Contributor Onboarding & SpecOps Workflow](01-getting-started.md).
